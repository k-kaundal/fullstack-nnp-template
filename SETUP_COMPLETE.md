## 🎯 Next Steps

### 1. Initial Setup

```bash
# Run the automated setup
chmod +x setup.sh
./setup.sh
```

### 2. Verify Installation

```bash
# Check backend
cd server
yarn lint
yarn test

# Check frontend
cd ../client
yarn lint
yarn build
```

### 3. Start Development

```bash
# Terminal 1: Backend
cd server
yarn start:dev

# Terminal 2: Frontend
cd client
yarn dev
```

### 4. Access Services

- Frontend: http://localhost:3000
- Backend: http://localhost:3001
- Swagger: http://localhost:3001/api/docs
- pgAdmin: http://localhost:5050 (admin@admin.com / admin)

## 🆘 Troubleshooting

### Common Issues

**Port Already in Use:**

```bash
# Kill process on port
lsof -ti:3001 | xargs kill -9
```

**Database Connection Failed:**

```bash
# Restart Docker
docker compose down
docker compose up -d
```

**Module Not Found:**

```bash
# Reinstall dependencies
rm -rf node_modules yarn.lock
yarn install
```
